Mode isolation and menu status, reviewed 2026-09-11

IMPLEMENTED RECORD HOOK
src/rowpatch_gated.S checks ARMED, row1936x1090 and FieldAngle selector r5==175.
It does NOT use live sensor-mode register C343B590. The previous mode117 gate
was abandoned because that register did not reliably identify hook-time state.
Earlier hardware observations found r5=175 for open-gate FHD29.97 and r5=180
for FHD25. Those observations support the targeted isolation fix, not all modes.

emulate_hook.py assembles current source and checks five row/selector/armed
cases, plus returned R0 and preserved R4/R5/SP. Previously it accidentally read
R4 under the name r0 and loaded a potentially stale builds/rowpatch_gated.bin.
The corrected emulator does not reproduce the whole camera pipeline or caches.

build_gated_autorun.py validates exact MAIN hash, original patch words and cave
space, then emits a cold-boot AutoRun. Its runtime has no firmware-version guard.
Picker slot7, mode117 timing and profile122 resize data are changed alongside
the code hook. Profile122 also belongs to stock FHD29.97; a table location is
not proof of inherent isolation. Every format/transition still needs testing.

LIVE HOST CONTROL
The reviewed toggle_opengate.py requires the matching cold-boot-installed code
and validates its digest. It changes ARMED data, not the live branch instruction,
and reports write/readback failures. It never enables after a failed table write.
Partial failure still requires recovery; no recording-idle interlock is known.

MENU
No working on-camera menu exists. The candidate handler is C0265800; C0269B50
is a deleting destructor. Actual dispatcher routing, key IDs, consumption,
rendering and allocation contracts remain unverified. The placeholder assembly
was withdrawn. See MENU-UI.md and SIDELOAD.md for the remaining design work.
A boot banner and use of SIGMA's own menu do not constitute a custom menu.

ADDITIONAL MODES
build_highfps_autorun.py experiments with slot4 M27->M58 and slot17 M88->M103.
Table-derived timing is not measured file cadence; matching sensor rasters
alone does not prove compatible downstream geometry or storage requirements.
The standalone HFR AutoRuns have no USB shell and should not be layered over
an open-gate session. No sustained120fps result has been verified.

Further sensor candidates in MODES.txt are research leads only. Before claiming
a working mode, validate the actual producer/buffer/stride, Bayer coverage,
recorded dimensions and unique-frame cadence, storage behavior, preview/playback,
and return to stock. Do not equate build success with hardware acceptance.
